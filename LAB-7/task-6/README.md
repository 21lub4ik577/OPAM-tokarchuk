# Завдання 6. Висновок

1. У Лабораторній 4 критерій був зашитий, тому для трьох критеріїв і трьох типів даних знадобилося б дев'ять окремих функцій. Тут достатньо одного `Filter<T>` і дев'яти переданих застосувань-предикатів: три критерії для трьох наборів; тіло алгоритму не змінюється.

2. Узагальнення було б зайвим у вимірюванні конкретного пошуку `int` у `List<int>` та `HashSet<int>` для фіксованих наборів із Лабораторної 6, завдання 5. Мета того коду — порівняти саме ці дві структури та їхню поведінку на конкретних розмірах, а не надати повторно використовувану бібліотеку пошуку; узагальнений API тут лише ускладнив би невеликий демонстраційний код.
